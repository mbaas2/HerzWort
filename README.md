# HerzWort

Ins Herz das Wort! Die App zum Lesen und Auswendiglernen der Bibel

Derzeit wird noch heftig entwickelt. Wegen Abhängigkeiten und um Probleme in Zusammenhang mit der (erlaubten) Nutzung geschützter Texte (die aber nicht in einem öffentlich zugänglichen) Repo landen sollten, halte ich den Code derzeit noch in einem privaten Repo. Wenn ein stabilerer Zustand erreicht ist, nehme ich mir die Zeit, das alles in Ordnung zu bringen und den Code zu veröffentlichen.

Mehr Info gibt auf https://herzwort.app wo ihr gerne die App ausprobieren könnt.

# HeartWort

Heart the Word! The App for reading and memorization of bible text

Still intensly under development. Because of dependencies and challenges related to dealing with (c) texts (that I have the permission to use, but that should not be made available in public repositories etc.), the code currently lives in a private repo. Once it has reached a more stable state has been reached, I am planning to arrange things properly uand to release the code here.

More info and access to the app itself at https://heartword.app
